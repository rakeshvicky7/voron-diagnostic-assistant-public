# Voron 0.2 diagnostic assistant (online demo, basic mode)

Assembly guide and repair assistant for the Voron 0.2r1 3D printer, with a 3D virtual printer built from the official CAD.

This online version runs the symptom graph only. The full version (with a local language model) runs offline on a laptop.
Accuracy on 69 held-out cases: basic mode 59 % right part first, 78 % within two checks; full mode 65 % and 91 %.

M.Sc. thesis prototype. Voron CAD and documentation: VoronDesign (GPLv3). three.js (MIT).
